## Завдання 2

Файл `university.sql`:
1. Створює таблиці (`students`, `courses`, `students_courses`).
2. Наповнює їх тестовими даними.
3. Виконує фінальний `SELECT` запит за умовою завдання.

### Як запустити скрипт

**Варіант 1**
1. Відкрийте онлайн-компілятор PostgreSQL, наприклад [DB Fiddle](https://www.db-fiddle.com/).
2. Скопіюйте весь вміст файлу `university.sql`.
3. Вставте код який створює таблиці та наповнює їх у ліву панель (Schema SQL), а запит в праву (Query SQL) і натисніть **Run**

**Варіант 2: Локальний запуск (якщо встановлено PostgreSQL)**
Ви можете виконати файл через термінал (psql), перебуваючи у папці з файлом:
```bash
psql -U ваш_користувач -d назва_вашої_бд -f university.sql
