# Quotes App (Frontend)

Це фронтенд-частина додатку для управління цитатами. Проєкт написаний на React з використанням Vite та стилізований за допомогою Tailwind CSS.

## Запуск проєкту

1. Відкрийте термінал у папці з фронтенд-проєктом.
2. Встановіть залежності, виконавши команду:
```bash
    npm install
```
3. Запустіть сервер розробки:
```bash
    npm run dev
```
